# 🌱 Plant Care Reminder System

## 📌 Project Overview
A SQL-based system designed to help users manage plant care schedules, including watering reminders and sunlight requirements.

## 🛠️ Tech Stack
- MySQL
- SQL

## 📂 Project Files
- schema.sql → Database structure
- sample_data.sql → Sample records
- queries.sql → Useful operations
- README.md → Documentation

## 🚀 Features
- Manage multiple plants
- Track watering schedules
- Generate reminders
- Update care status

## 📊 Sample Queries
- Get plants by user
- Find plants needing watering today
- Update reminder status
